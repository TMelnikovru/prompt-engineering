# DSBA Online

Интеграция открытых данных https://dsba.online/ с выбором программы, курса,
группы и подгруппы во фронтенде. Авторизация пользователей приложения будет
отдельным шагом; текущий выбор относится к публичной учебной группе.
Приватный Google Classroom, оценки, аккаунты, загрузка файлов и изменения
на стороннем сайте не используются.

## Проверка доступа 25 октября 2026

Главная страница и JSON доступны с рабочей машины и `docker-prod` без входа.
`GET /api/config` возвращает `access=open`, учебный год и каталог программ.
Публичный клиент `/app.js` читает `GET /api/subjects`, `/api/materials`,
`/api/deadlines` с `program`, `year`, `group`, `sub`, `mine`. Коннектор использует
те же GET-запросы и проверяет выбор по текущему каталогу.
Это наблюдаемый интерфейс сайта; опубликованная OpenAPI-спецификация не найдена.
Если сайт потребует вход, коннектор вернёт ошибку, сохранив принятые ранее данные.

На `/about` сайт обозначен как неофициальный студенческий проект. Его сведения
сохраняются с атрибуцией DSBA Online и ссылкой на указанный им первоисточник.
Противоречие, указанное самим DSBA, не превращается в подтверждённый срок.

## Запрос из фронтенда

1. `GET /api/v1/integrations/dsba/catalog` — программы, курсы, группы,
   подгруппы, ID предметов и доступные названия.
2. `POST /api/v1/integrations/dsba/sync` — выбранные значения:

```json
{"program":"dsba","year":1,"group":"261","sub":"1","subjects":[]}
```

Значения выше иллюстрируют формат, не задают профиль студента по умолчанию.
`subjects` — необязательный список ID дисциплин (`mine` на стороне DSBA).
При пустом списке действует стандартный набор выбранной группы.
Группа обязательна, когда она есть в каталоге курса. Если групп у курса нет,
передаётся пустая строка. Подгруппу можно оставить пустой строкой.

3. Ответ содержит `source_id` вида `dsba:<hash>`. Сохранить его вместе с выбором.
   Передавать в `GET /api/v1/dashboard?dsba_source_id=...` и
   `GET /api/v1/documents?source_id=...`. Без `dsba_source_id` dashboard не
   показывает задания произвольной ранее подключённой группы.

`source_id` — идентификатор набора публичных данных, не токен авторизации.
Личные аккаунты и разграничение приватных данных им не заменяются.
После появления аккаунтов пользователь сможет ссылаться на выбранный набор.

POST сохраняет результат синхронизации и её ошибки. Повторный запрос в течение
60 секунд использует последний запуск; 409 означает занятый обработчик.
400 — выбор отсутствует в каталоге, 422 — неверный формат, 429 — лимит наборов,
502 — источник недоступен, 503 — БД недоступна. Ошибка после создания запуска
возвращает сохранённый отчёт с `source_id`, остальные ошибки — стандартный `ApiError`.
Токен оператора в браузер не передаётся: эта операция читает только фиксированный
публичный источник и проверенные параметры каталога.

На странице «Источники» есть форма подключения. Выбор хранится в localStorage
данного браузера; сервер хранит записи и настройки автоматического обновления.

## Факты и история

Каждый набор имеет свой `IngestionSource`, сообщения API — стабильные
`deadline:<id>` / `material:<id>`, содержимое — неизменяемые `DocumentVersion`.
Повторная загрузка не создаёт дубликаты. Обновлённый срок меняет текущую версию
того же задания, сохраняя старое подтверждение и объяснение изменения.
Дата без времени остаётся `due_date`; точное время принимается только с явным
часовым поясом. Неоднозначный или некорректный срок не додумывается.
Публичное `status` DSBA не считается фактом сдачи работы конкретным студентом.

Полный успешный ответ endpoint может пометить исчезнувшие записи неактивными.
Их история остаётся доступна через `documents/{id}` с `is_active=false`.
Частичная загрузка, таймаут и достигнутый лимит не снимают прежние записи.
Ошибки не обновляют время последней успешной синхронизации.

Сроки извлекаются из структурированных полей, без OpenAI. DSBA-записи
пропускаются в автоматическом LLM-разборе вики. Приоритет `medium` —
начальная рекомендация. План дня и личная отметка выполнения ещё не реализованы.

Материалы сохраняются как карточки с метаданными и ссылками на оригинал/файл,
а не как извлечённый текст PDF. Закрытые файлы не скачиваются. Это не полная
копия сайта или архива материалов.

## Автоматическое обновление

`dsba-worker` запускается на сервере через Compose с `restart=unless-stopped`.
Он читает выбранные наборы из PostgreSQL независимо от открытой вкладки.
Настройки: `HSE_DSBA_INTERVAL_SECONDS` (900), `HSE_DSBA_REQUEST_TIMEOUT` (20),
`HSE_DSBA_MAX_RECORDS` (1000 на endpoint), `HSE_DSBA_MAX_PROFILES` (40).
Полный отказ одного набора не останавливает вики и другие наборы DSBA.
После ошибки повторная попытка возможна не раньше чем через 60 секунд;
worker проверяет очередь каждые 30 секунд.
`HSE_DSBA_BASE_URL` позволяет проверять тот же код против HTTP-симуляции.

```sh
uv run python -m app.dsba catalog
uv run python -m app.dsba sync --program dsba --year 1 --group 261 --sub 1
uv run python -m app.dsba worker
```

## Проверки

`tests/test_dsba.py` обращается к настоящему HTTP stand-in, основанному на
наблюдаемых JSON-формах. `tests/test_dsba_integration.py` проверяет поток
через FastAPI, PostgreSQL, версии и worker: разделение групп, кэш повторов,
смену срока, сохранность при отказе, снятие исчезнувших записей и восстановление.
Данные mock явно синтетические; успешный mock не считается подключением DSBA.

Postman: `postman simulation run postman/simulations/dsba-ingestion.sim.yaml
--port 4912 --no-history --output ndjson`. Контекст запуска — рядом с sim.yaml.
