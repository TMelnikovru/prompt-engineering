# Объединение PostgreSQL, фронтенда и DSBA

Согласованы main 559de32, frontend 8e89531 и backend/DSBA 5397525.
История веток сохранена merge-коммитами; Telegram в это объединение не входит.

- Сохранены новый интерфейс ВШЭ, темы, навигация, локальный профиль,
  страницы материалов и оценок. Оценки пока остаются экраном будущей функции.
- PostgreSQL хранит источники, версии, запуски и ИИ-результаты. Миграция 0003
  сохраняет историю снятых источником записей через is_active.
- Группа DSBA выбирается при входе и подключается автоматически; её ID передаётся в dashboard.
  Дедлайны и самостоятельные материалы ограничены выбранной группой.
- Экран «Материалы» объединяет dashboard.materials с tasks[].materials;
  ссылки ведут в источник, отсутствие задания не скрывает карточку.
- Общая модель Source/SourceView и состояния, включая partial, сохранены.
  Имена полей и фактические ограничения описаны в FRONTEND.md и openapi.json.
- Локальный профиль хранится только в браузере, не заменяет серверный вход
  и подключает только выбранную пользователем публичную группу.

Deploy сначала применяет миграции, затем запускает app, wiki-worker и
dsba-worker. Нужны серверные PostgreSQL-параметры и OPENAI_API_KEY для ИИ-вики.
Секреты остаются на сервере. Базы main и preview независимы; объединение кода
не копирует данные и выбранные группы между ними.

Проверки: pytest с отдельной PostgreSQL, HTTP stand-ins вики/OpenAI/DSBA,
контракты JS и HTML, актуальность OpenAPI, Docker/deploy в CI. Ручной сценарий:
вход с выбором DSBA → Задания → Материалы → обновление; «Источники» показывает статус.
