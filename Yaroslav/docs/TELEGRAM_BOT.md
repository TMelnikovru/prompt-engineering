# Telegram-бот и открытые каналы

Бот заменяет личный аккаунт для групп. Ему не нужны номер телефона, `api_id` и файл
сессии: бот виден участникам чата и читает только чаты, куда его добавили.

## Открытые каналы — без бота и аккаунта

Агент читает веб-страницу `https://t.me/s/<канал>`, ту же, что видна в браузере
любому человеку. Список каналов задаётся в `.env`:

~~~sh
HSE_TELEGRAM_PUBLIC_CHANNELS=["@dsba_hse", "@hse_fcs"]
~~~

Берутся посты за `HSE_TELEGRAM_HISTORY_DAYS` (по умолчанию 7 дней), не больше
`HSE_TELEGRAM_PUBLIC_PAGES` страниц по ~20 постов. Обновление идёт каждые 10 минут.
Правка поста сохраняется как новая версия. На странице видны имена файлов, но
не их содержимое. Закрытые каналы так не читаются (`telegram_channel_not_public`).

## Бот

1. @BotFather → `/newbot` → имя и username, заканчивающийся на `bot`. Получите токен.
2. @BotFather → `/setprivacy` → бот → **Disable**. Иначе в группах бот видит только команды.
3. В `.env`:

   ~~~sh
   HSE_TELEGRAM_BOT_TOKEN=<токен>
   HSE_TELEGRAM_BOT_OWNER=@ваш_username
   ~~~

4. Напишите боту `/start`. С этого момента он знает ваш чат для напоминаний.
   Другим пользователям бот отвечает, что он личный, и ничего им не показывает.
5. Добавьте бота в учебные группы. Он сохраняет новые сообщения: старую историю
   Bot API не отдаёт.

Проверка без записи в базу и запуск:

~~~sh
.\.venv\Scripts\python.exe -m app.telegram_bot check
.\.venv\Scripts\python.exe -m app.telegram_bot worker
~~~

В Docker Compose это сервис `telegram-bot`.

## Что делает бот

- **Сообщения групп** сохраняет в источник `telegram_bot`. Вместе с открытыми каналами
  они попадают в ИИ-сводку на странице `/telegram`.
- **Напоминания**: за `HSE_TELEGRAM_REMINDER_HOURS` часов до срока (по умолчанию 24 и 3)
  присылает задание из SmartLMS (и DSBA, если задан `HSE_TELEGRAM_REMINDER_DSBA_SOURCE`).
  Отправленные напоминания хранятся в PostgreSQL, поэтому перезапуск не даёт дублей.
  Если бот был выключен и пропустил окно, придёт одно напоминание, а не несколько.
  Перенос срока создаёт новое напоминание.
- **`/plan`** — план на сегодня (`HSE_TELEGRAM_PLAN_MINUTES`, по умолчанию 120 мин),
  тот же расчёт, что на сайте.

Ограничения: отметки «Готово» хранятся в браузере, поэтому бот о них не знает и
может напомнить о сданном. PDF из групп пока не скачиваются, сохраняется имя файла.
Запущенный бот читает обновления сам, второй экземпляр с тем же токеном получит
`telegram_bot_conflict`.
