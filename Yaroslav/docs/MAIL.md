# Почта ВШЭ

Студенческая почта ВШЭ работает на Яндекс 360, поэтому коннектор читает её по IMAP
(`imap.yandex.ru:993`, SSL). Хост и порт настраиваются, так что подойдёт и другой
IMAP-сервер.

## Подключение

1. В почте Яндекса включите доступ по IMAP: «Все настройки» → «Почтовые программы».
2. Создайте пароль приложения: id.yandex.ru → «Безопасность» → «Пароли приложений» →
   «Почта». Основной пароль ЕЛК не используйте. Если пункта нет, администратор
   Яндекс 360 ВШЭ мог отключить пароли приложений. Тогда этот способ не сработает:
   зафиксируйте ограничение и не обходите его.
3. Заполните в серверном `.env`:

   ~~~sh
   HSE_MAIL_USERNAME=ivanov@edu.hse.ru
   HSE_MAIL_PASSWORD=<пароль приложения>
   ~~~

4. Проверьте вход без записи в базу:

   ~~~sh
   uv run python -m app.mail check
   ~~~

   Команда выводит число писем и до 10 тем. Ошибки возвращаются кодами без
   подробностей сервера: `mail_auth_failed`, `mail_timeout`, `mail_network_error`,
   `mail_folder_unavailable`.

## Как работает

- Только чтение: папки открываются в режиме read-only, письма запрашиваются через
  `BODY.PEEK[]`. Статус «прочитано» в ящике не меняется.
- Берутся письма за `HSE_MAIL_LOOKBACK_DAYS` (по умолчанию 30) из папок
  `HSE_MAIL_FOLDERS` (по умолчанию `["INBOX"]`). Обрабатывается не больше
  `HSE_MAIL_MAX_MESSAGES` писем, новые идут первыми.
- В базу и к модели попадают только письма с доменов `HSE_MAIL_ALLOWED_SENDER_DOMAINS`
  (по умолчанию `["hse.ru"]`, включая поддомены вроде `edu.hse.ru`). Личная переписка
  остаётся в ящике. `[]` снимает фильтр.
- Письмо хранится как документ источника `mail`. Ключ — хеш `Message-ID`, поэтому
  повторная синхронизация и копии письма в разных папках не создают дубликатов.
  Вложения не скачиваются, их имена добавляются в текст.
- `mail-worker` в Compose синхронизирует ящик каждые `HSE_MAIL_INTERVAL_SECONDS`
  (по умолчанию 600 секунд). При ошибках интервал сокращается, повторы идут с
  нарастающей паузой. Затем запускается общий этап ИИ-извлечения кандидатов
  в задания, тот же, что у вики. Без настроенного ящика воркер ничего не пишет в базу.
- Ручной проход: `uv run python -m app.mail sync --analyze`.

Ограничение: извлечённые кандидаты пока не становятся персональными заданиями
в dashboard. Этот шаг общий для всех источников, он описан в AGENTS.md.
