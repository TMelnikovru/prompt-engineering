# Интеграции

Здесь добавляются коннекторы SmartLMS, почты, РУЗ, ЕЛК, Telegram и вики ФКН.
PDF извлекается из материалов этих источников, это не отдельная учётная запись.

Начните с проверки реального доступа с сервера. Общая граница — протокол
`Connector` и записи `SourceRecord` в `base.py`. Пара
`(source_id, external_id)` должна устойчиво определять исходную запись.
HTML/PDF предварительно преобразуются в текст; подтверждающие ссылки сохраняются.

Ни один коннектор сейчас не реализован. Успех HTTP-запроса к нашему API
или наличие учебного примера не означает успешного подключения к университету.
Ключи, cookies и сессии держите вне репозитория.
