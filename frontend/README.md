# Рабочее место фронтенда

- `templates/index.html` — разметка, экран загрузки и все разделы.
- `static/css/app.css` — токены бренда ВШЭ, сетки, адаптивность, анимации.
- `static/js/api.js` — HTTP-клиент и обработка ошибок.
- `static/js/app.js` — отображение данных, навигация, фильтры, перенос срока.
- `static/icons.svg` — локальные SVG-иконки.
- `static/fonts/` — HSE Sans (woff2) с официальной страницы брендбука
  [hse.ru/info/brandbook](https://www.hse.ru/info/brandbook/). Внешних CDN нет.

Запуск из корня: `uv sync`, затем `uv run uvicorn app.main:app --reload`.
Открыть http://127.0.0.1:8000. Node.js и сборщик для фронтенда не нужны.
При изменении CSS/JS/HTML обновите страницу браузера.

Начните с [контракта и сценариев](../docs/FRONTEND.md).
Данные приходят только через `api.js`: при подключении реального бэкенда
разметку и стили менять не требуется, если контракт сохранён.

## Дизайн

- Цвета взяты с hse.ru: синий `#1d4aa8` для меню и крупных плоскостей, яркий
  `#0050cf` для кнопок и ссылок, светло-голубой `#90ceff`, светлые `#d6e8fd`,
  `#9cc3f2`, текст `#13285c`. Тёмно-синий с голубым (`#0f2d69` + `#0fa0d7`)
  не используем: слишком похоже на ВТБ. Оранжевый `#f08a5d` только для сроков
  «сегодня».
- Шрифт HSE Sans: Black для заголовков, Thin для крупных цифр.
- Паттерн из параллелограммов по брендбуку: экран загрузки, хиро, разделы «скоро».
- Анимации: View Transitions между разделами, появление блоков по очереди,
  FLIP при перестройке плана, счётчики. `prefers-reduced-motion` всё отключает.

- Тема «Вкусно и точка» (пожелание с доски команды): кнопка с палитрой в шапке
  или «Настройки → Оформление». Меняет только палитру через `data-theme="vit"`
  на `<html>`, без логотипов. Новая тема раскрывается кругом из точки клика.
- Статус связи в шапке: «Связь Вааааась» при ответе сервера,
  «Связь потеряна, Вааась» при ошибке или потере интернета.
- Ширину левого меню можно тянуть за правый край (208–380 px).

## Разделы

`#today`, `#tasks`, `#materials`, `#grades`, `#settings` — основное меню; `#sources` — внизу меню;
`#account` — ФИО, программа, курс, группа, подгруппа, изменение профиля и выход.
В мобильной версии он доступен из «Настройки → Учебный профиль».
«Оценки» пока честный экран «скоро»: данных
об оценках в API нет.

## Материалы

`#materials` объединяет `dashboard.materials` и `task.materials`, группирует по курсам. Поиск
ищет по названию материала, курсу и заданию; «Нужно сегодня» оставляет материалы
заданий из сегодняшнего плана или со сроком сегодня. «К заданию» открывает карточку
задания. Самостоятельные материалы открываются по ссылке на источник.

## Вход

В live-режиме после загрузки открывается окно входа: ФИО, программа, курс,
группа, подгруппа и необязательные дисциплины из каталога DSBA. Вход сам вызывает
sync и загружает dashboard с полученным source_id. Ручной формы в «Источниках»
нет. В демо-режиме для просмотра учебных примеров вход не требуется.

`dsba.js` управляет формой, а `dsba-profile.js` проверяет сохранённый профиль и
выбор по каталогу. Канонический профиль: `hse-agent:profile` с `name`, `group`,
`dsba: {source_id, selection}`. Старый ключ `hse-dsba-selection` поддерживается
для перехода с прежней формы. ФИО на сервер не отправляется; сервер получает
только выбор DSBA. API серверной авторизации пока нет.
Сервер выдаёт CSS/JS по общему `/static/<version>/…`: относительные импорты
получают ту же версию. После правки статики в dev перезапустите сервер для
новой версии; HTML перепроверяется браузером при загрузке.

## Что хранится в браузере

`localStorage` с префиксом `hse-agent:`:

- `deadlines` — последний известный срок каждого задания. Если после обновления
  срок другой, интерфейс показывает перенос: старая дата зачёркивается, новая
  въезжает, карточка подсвечивается, приходит уведомление. Если API начнёт
  отдавать `previous_due_at` / `previous_due_date`, фронт возьмёт их.
- `changes` — найденные переносы (держатся 3 дня).
- `theme`, `sidebar`, `profile` — тема, ширина меню, ФИО и параметры DSBA.
- `done`, `overrides`, `settings` — отметка «готово», правки приоритета и времени,
  настройки. Это временная замена API: интерфейс прямо пишет, что данные
  живут только в этом браузере.

Чтобы показать перенос на демо без бэкенда, в консоли браузера:

~~~js
const k = "hse-agent:deadlines";
const d = JSON.parse(localStorage.getItem(k));
d["demo-algorithms"] = "2026-10-24T18:00:00+03:00";
localStorage.setItem(k, JSON.stringify(d));
~~~

затем нажмите «Обновить план». Это подготовленная проверка интерфейса,
а не реальное изменение в источнике.
